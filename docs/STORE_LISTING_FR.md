# Store Listing Draft (FR)

Titre : SplitForge
Sous-titre : Planificateur de splits pour courses hybrides

Description courte :
Creez vos modeles, assignez les stations et obtenez une estimation en direct.

Description longue :
SplitForge est un planificateur local pour l'entrainement aux courses hybrides. Creez vos modeles run + station, planifiez en solo ou en doubles et voyez les estimations de temps en direct.

Gratuit :
- Un modele personnalise
- Profils athletes solo ou doubles
- Estimation en direct et charge par athlete

Pro (achat unique) :
- Modeles illimites
- Suggestions automatiques
- Export/partage d'un resume
- Deltas what-if

Pas de comptes. Pas d'analytics. Vos donnees restent sur votre appareil.

Mots-cles :
course hybride, planificateur de splits, entrainement course, strategie doubles, estimation temps

Avertissement :
SplitForge est un outil independant et n'est associe a aucun evenement ni marque.
