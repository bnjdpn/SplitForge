# Store Listing Draft (EN)

Title: SplitForge
Subtitle: Hybrid race split planner

Short description:
Build hybrid race templates, assign stations, and get live finish estimates.

Long description:
SplitForge is a local-first split planner for hybrid race training. Build your own run + station templates, plan solo or doubles strategies, and see live time estimates as you adjust assignments.

Free features:
- One custom template
- Solo or doubles athlete profiles
- Live time estimation and workload breakdowns

Pro unlock (one-time):
- Unlimited templates
- Auto split suggestions
- Export/share summary image
- What-if deltas

No accounts. No analytics. Your data stays on your device.
